# Avti branding layer

This fork intentionally keeps internal `dsh-*`, `@deepseek-ai/*`, and CSS class identifiers unchanged to reduce future upstream merge conflicts.

User-facing identity is **Avti** with application id `com.dantegolf.avti`.

Visual tokens follow the existing AvtiCode desktop UI: light neutral surfaces and purple accent `#6754f5`.

Automatic updates from `dshdesktop.cn` are disabled. Avti should only enable updates after publishing and signing its own release artifacts.
