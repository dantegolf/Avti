### 1. The Quantum Singularity Core (ANSI Half-Block Emblem)
* **Technique:** Sub-pixel ANSI half-block (`▀` / `▄`) high-density rendering packing two vertical pixels per character cell.
* **Palette:**
  * **Electric Cyan** (`#00F5FF` / ANSI 51) — The energy boundary & primary prompt accent.
  * **Quantum Violet** (`#A855F7` / ANSI 141) — The cognitive reasoning & telemetry field.
  * **Lumina White** (`#FFFFFF`) — The event horizon singularity core.
  * **Obsidian Slate** (`#334155`) — Precision structural box frames.

### 2. The 6-Spectrum Theme Engine
Avti ships with 6 truecolor and ANSI-optimized themes, selectable on the fly via `/theme <name>`:
1. **`aurora` (Signature Default)**: Electric Cyan & Quantum Purple on Obsidian Black.
2. **`antigravity`**: Cyberpunk Violet & Quantum Magenta Singularity.
3. **`solar-amber`**: Warm Amber & Golden CRT Phosphor glow.
4. **`cyber-matrix`**: High-Tech Matrix Phosphor & Terminal Jade.
5. **`ice-slate`**: Nordic Frost & Arctic Glacial Slate Blue.
6. **`clean-mono`**: Minimalist high-contrast pure monochrome for low-color terminals.

## ⚡ Core Architecture & Engineering Pillars

| Architectural Layer | Implementation | Developer Benefit |
|---------------------|----------------|-------------------|
| **Local Bridge Protocol** | Zero-latency reverse proxy to Antigravity (`127.0.0.1:8080`) | Privacy-first local LLM execution, zero cloud roundtrips, 95+ TPS throughput |
| **Telemetry HUD Deck** | Real-time segmented context gauges (`[████░░░░]`), TPS sparklines (` ▂▄▅▇█`) | Immediate visibility into memory, tokens, cache rates, and model speed |
| **Interactive Popover Palette** | Non-blocking floating box-drawing palette on `/` | Rapid command execution, fuzzy matching, and categorized tool discovery |
| **Structured Tool Cards** | Color-coded status frames with timing metrics and ANSI diffs | Clean, readable tracking of code modifications, grep searches, and test runs |
| **Zero-Interruption Multi-Motion** | Autonomous phase transitions (Thinking → Accelerating → Executing) | Smooth, flicker-free terminal updates with sub-millisecond frame pacing |
