## Что такое Avti

Avti — десктопное приложение на Electron, построенное вокруг runtime-пакетов DeepSeek Harness. Этот репозиторий содержит собственную оболочку Avti, нативную интеграцию с операционной системой, profiles, терминал и диагностические сервисы, а также встроенный рынок community-плагинов.

Задача приложения простая: открыть локальный проект и держать AI-агента, контекст проекта, локальные инструменты и расширяемые плагины в одном рабочем процессе, без необходимости вручную собирать несколько CLI-сервисов.

## Что уже работает

- **Проекты и рабочие пространства**: создание и переключение workspaces, выбор локальных папок, перетаскивание папок в десктопное приложение и нативный выбор директории в Windows.
- **Диалоги с агентом и локальные инструменты**: сессии Harness, tools, commands, attachments, среда выполнения кода, permissions и sandbox-возможности для работы с проектом.
- **Трёхпанельный десктопный интерфейс**: боковая панель, область диалога и панель деталей внутри нативного окна; ширину боковой панели и панели деталей можно менять, а для macOS и Windows предусмотрена работа с нативной строкой заголовка.
- **Локальный терминал**: desktop runtime интегрирует terminal- и shell-сервисы. В текущей Linux-конфигурации terminal plugin по умолчанию отключён.
- **Profiles**: можно хранить и переключать отдельные конфигурации desktop/runtime, чтобы управлять окружением проектов и плагинов по профилям.
- **Встроенный рынок плагинов**: `dsh-community-market` подключён к приложению и поддерживает каталог плагинов, карточки, источники, установку, удаление и управление.
- **Встроенный pnpm и сервисы установки плагинов**: Avti умеет управлять пакетами, которые используют плагины, и содержит rollback/recovery-логику на случай неудачных изменений конфигурации.
- **Системный трей и нативная интеграция**: реализованы tray-иконки, поведение нативного окна, платформенные адаптеры и desktop startup lifecycle.
- **Логи и диагностика**: в репозитории реализованы локальное логирование, экспорт диагностики, проверка здоровья renderer при запуске, сбор данных о сбоях и восстановление после проблем со стартом.
- **Сборка приложения**: есть процесс сборки Windows x64 в виде NSIS installer и portable-архива, сборка для macOS и Linux directory target.

## Текущие ограничения

У Avti **пока нет собственного подписанного канала автоматических обновлений**. Updater намеренно отключён, чтобы сборки Avti не обращались к update-сервису исходного проекта.

В репозитории также **нет и не заявляется функция удалённого управления с телефона**. В этом README перечислены только возможности, которые реально присутствуют в текущем коде.

## Разработка

Требования:

- Node.js `^22.19.0` или `>=24.0.0`
- Yarn `4.18.0`

Установка зависимостей и запуск приложения для разработки:

```bash
yarn install
yarn dev
```

Основные команды:

```bash
yarn build
yarn typecheck
yarn test
yarn check
yarn dist:win
yarn dist:win-portable
yarn dist:mac
```

## Структура репозитория

- `dsh-plugin-desktop/` — Electron-оболочка Avti и desktop-сервисы
- `dsh-community-market/` — каталог плагинов, интерфейс marketplace и процессы установки/удаления
- `dsh-community-fabric/` — совместимость плагинов и работа с контрактами
- `patches/` — compatibility-патчи для зафиксированных runtime-зависимостей

## Open-source компоненты и лицензии

Avti использует runtime-пакеты DeepSeek Harness и другие open-source компоненты, но сам Avti является отдельным десктопным продуктом, который поддерживается в этом репозитории и не использует канал обновлений upstream DSH Desktop.

Лицензия проекта находится в [`LICENSE`](LICENSE). Список сторонних компонентов и лицензий, используемых desktop-пакетом, находится в [`dsh-plugin-desktop/THIRD_PARTY_NOTICES.md`](dsh-plugin-desktop/THIRD_PARTY_NOTICES.md).
